# Практическая работа №7

**Тема:** Первое полноценное ООП-приложение. Корпоративный заказ оборудования.

**Вариант:** 4  
**Язык программирования:** Java 21+

## Описание проекта

Консольное Java-приложение для формирования корпоративных заказов оборудования.

Программа позволяет создавать заказы сотрудников, добавлять и удалять товары, объединять одинаковые позиции, рассчитывать стоимость и подтверждать заказы.

## Индивидуальный вариант №4

Реализованы два требования:

- Максимальное количество уникальных позиций в заказе — 10. Попытка добавить одиннадцатую позицию вызывает `IllegalStateException`.
- Метод `addPositionCount(Order order)` возвращает количество уникальных позиций заказа.

## Структура приложения

- `Product.java` — данные товара и проверка корректности параметров.
- `Employee.java` — данные сотрудника.
- `OrderItem.java` — позиция заказа, количество и стоимость.
- `Order.java` — управление заказом и бизнес-правила.
- `OrderStatus.java` — статусы заказа.
- `OrderService.java` — создание заказов.
- `SelfCheck.java` — тестирование и интерактивный режим.

## Требования

- Java SE 21 или новее.
- Компилятор `javac`.
- Терминал для запуска.

Maven, Gradle и сторонние библиотеки не используются.

## Сборка и запуск

Находясь в корневой папке проекта, выполните:

```bash
mkdir -p out
javac -encoding UTF-8 -d out $(find src -name "*.java")
java -cp out ru.edu.pr04.SelfCheck
```

## Режимы приложения

**1. Unit-тестирование**

25 проверок корректности работы приложения, включая индивидуальный вариант.

**2. Data-driven тестирование**

Программа загружает данные из `data/sample.csv` и проверяет результаты добавления товаров, объединения позиций, обработки ошибок и расчёта стоимости.

**3. Интерактивный режим**

Команды:

| Команда | Назначение |
|---|---|
| `add <id> <name> <price> <qty>` | Добавить товар |
| `remove <id>` | Удалить позицию |
| `items` | Вывести состав заказа |
| `total` | Показать стоимость |
| `status` | Показать статус |
| `confirm` | Подтвердить заказ |
| `exit` | Завершить программу |

Название товара в интерактивном режиме вводится без пробелов.
